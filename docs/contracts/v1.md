# dbt-agents v1 public contract

This document is normative for configuration `version: 1`. The rationale is in
[ADR-0001](../adr/0001-v1-contract-freeze.md).

## Compatibility rule

Patch and minor releases may add optional configuration fields, response fields,
or new tools. They must not remove or rename the items below, make an optional
input required, change a field's meaning, or weaken a safety default.

## MCP tools

| Tool | Class | Stable purpose |
|---|---|---|
| `project_get` | Read | Return sanitized project capabilities and boundaries. |
| `repo_search` | Read | Search bounded, non-protected repository text. |
| `repo_read` | Read | Read a bounded UTF-8 file and return its hash. |
| `repo_status` | Read | Return Git branch, status, and optional diff. |
| `dbt_inspect` | Read | Read dbt project metadata and artifacts. |
| `dbt_compile` | Bounded compute | Compile selected dbt resources. |
| `warehouse_describe` | Read | Describe one allowlisted relation. |
| `warehouse_query` | Bounded compute | Dry-run and optionally execute one read query. |
| `change_plan` | Read/state | Create an exact, expiring, one-use write plan. |
| `repo_apply_patch` | A2 write | Replace one allowlisted file with a hash guard. |
| `dbt_test` | A2/A3 write | Run selected dbt tests after approval. |
| `dbt_execute` | A2/A3 write | Run/build selected dbt nodes after approval. |
| `git_publish` | A2/A3 write | Branch, commit, push, or create a PR. |

Tool schemas are generated from the typed functions in `server.py` and tested
by name, required arguments, and annotations. Structured output may gain fields
but retains `ok`, `operation_id`, `project`, and `operation`.

## Configuration

- Canonical filename: `dbt-agents.yml`
- Schema: `schemas/config.schema.json`
- Required root fields: `version`, `projects`
- Current version: integer `1`
- Unknown fields are rejected at every level.

The following safety defaults are stable:

| Field | Default |
|---|---:|
| `warehouse.allow_raw_rows` | `false` |
| `limits.query_max_bytes_billed` | `1,000,000,000` |
| `limits.query_timeout_seconds` | `60` |
| `limits.query_max_rows` | `100` |
| `limits.query_max_result_bytes` | `2,000,000` |
| `limits.query_max_cell_chars` | `10,000` |
| `dbt.allow_full_refresh` | `false` |

## Authentication

The accepted `warehouse.auth.mode` values are `adc`, `impersonation`,
`service_account_file`, and `workload_identity`.

## Git publishing

The accepted `git_publish.action` values are `branch`, `commit`, `push`, and
`pr`. Clients must not infer support for other Git or GitHub operations.

## Support boundary

See the exact supported and unsupported environments in ADR-0001.
